# MCV Frontend Internship

This repository contains all of my **frontend internship tasks** for MCV.

## Project Purpose

The goal of this repository is to practice core frontend skills through multiple tasks and exercises, including:

- HTML structure
- CSS styling
- layout and spacing
- responsive design
- simple UI components

## Files

- `index.html` - current frontend task page
- `index.css` - styling for the current task
- `WhatsApp Image 2025-01-04 at 14.30.20_5275eaa5.jpg` - image used in the current example

## What I Learned

- Building layouts with semantic HTML
- Styling with CSS
- Using `object-fit` to control image display
- Creating reusable frontend components
- Improving UI structure and responsiveness

## How to Run

1. Open `index.html` in a browser.
2. Make sure the image file stays in the same folder as the HTML file.
